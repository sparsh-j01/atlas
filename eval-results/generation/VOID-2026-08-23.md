# VOID — do not cite `latest.json` / `latest.md` from run `78d34f34`

The Phase 2B generation run of **2026-08-23T19:09:07Z** is withdrawn. Its numbers measure the
Gemini free-tier rate limiter, not this pipeline.

## Why

- **43 of 45 regenerations** were `provider returned 429: You exceeded your current quota`.
- **5 slides were generated out of 50 queries.** The other 45 queries never reached the model.
- **"Abstention Accuracy 100.0% (10/10)" was a false pass.** All ten unanswerable queries
  errored with 429, and the classifier scored "no slide produced" as a correct judge refusal
  regardless of cause. That number would have been identical with the API key removed.
- **Groundedness 12.5% / Correctness 12.5%** are quota exhaustion, not model quality.
- The artifact names model `gemini-3.7-flash`, which nothing verified — the model id was a
  hardcoded constant, never read from the provider that served the requests.

## What changed since

| Fix | Where |
|---|---|
| `inconclusive` classification; provider failures excluded from every denominator | `evals/generation/generator.ts`, `metrics.ts` |
| `Verdict.unavailable` so an unreachable judge is not scored as a refusal | `lib/ai/verify.ts` |
| Model id resolved from the provider seam at run time | `lib/ai/generate.ts` → `generationConfig()` |
| Per-call rate limiter (`EVAL_RPM`, default 10/min) + pre-run call budget | `evals/generation/benchmark.ts` |
| `answerability` and `relevance` deleted — they were duplicates of `supported_generation` | `evals/generation/metrics.ts` |
| Schema validity moved to attempt level so it can fail | `evals/generation/metrics.ts` |
| 17 new tests, including a regression guard for the false abstention | `generator.test.ts`, `metrics.test.ts` |

## To produce a citable run

```bash
# one document at a time; watch the printed call budget
EVAL_RPM=8 npm run eval:generation -- openstax-social-psychology
```

The run now prints a WARNING and reports an `inconclusive` count whenever queries failed to
reach the model. **A run with a non-zero inconclusive count is not publishable** — lower
`EVAL_RPM` and repeat.
